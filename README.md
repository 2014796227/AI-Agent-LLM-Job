# AlphaDesk · 可信的 AI 投研助手

> **一句话定义**：面向投资新手的 AI 投研产品——一句话提问，获得带**可核查证据链**的研究报告与策略回测。核心主张：**可信**（每个数字可溯源、每个引用可点开官方原页、每个失败如实报告）。
>
> **项目性质（如实）**：个人求职作品（AI 产品经理方向）。产品决策 16 项全部本人拍板（`docs/pm/产品文档.md`），工程由 AI 编码助手按本人蓝图实现；单机演示部署，输出仅供研究演示，**不构成投资建议**。

## 产品定位

| 项 | 定义 |
|---|---|
| 第一用户 | 投资新手：会提问、想看 AI 的分析，但缺乏验证能力 |
| 第一痛点 | 研究效率低（一句话 vs 几小时翻多工具）；第一顾虑是 AI 不可信 |
| 核心主张 | 可信优先——**效率是入口，可信是留存** |
| 差异化主打 | **可核查证据链**：数据溯源条（来源/行数/拉取时间）+ 引用点开巨潮官方年报原 PDF 页 |
| Roadmap | P1 = 新手教育模式（从"给答案"到"教理解"）；做减法 = 术语白话化 |

完整产品文档（背景/用户/痛点/功能优先级/流程图/边界/埋点方案）：**`docs/pm/产品文档.md`**

## 核心体验（线上 http://43.156.248.38）

1. **一句话投研报告**：自然语言 → 多 Agent 协作（research/strategy/writer + critic 审查回路）→ 带图表与引用的报告；执行时间线实时可见、断线可回放
2. **白名单策略回测**：自然语言策略 → 净值曲线 + 指标 + 假设边界脚注（白名单外明确拒绝，不伪造）
3. **可核查的知识库问答**：巨潮官方年报节选 + 120 条本人逐条审核的方法论库；引用 `[[doc#页]]` 点击渲染原 PDF 页
4. **数据溯源面板**：每份行情标注来源（东方财富/腾讯财经，AKShare 接口）、行数、拉取时间——可用任意行情 App 当场核对
5. **失败可解释**：任务失败显示原因分类与应对建议；预算降级产出带标注的部分结果——**失败体验是产品的一部分**

## 明示边界（产品口径）

- 不能实盘交易；不输出合规意义的投资建议；回测为历史模拟（成交假设随报告展示）
- **AI 会错**：数字可核查 ≠ 结论正确——请批判使用
- 免费数据源无 SLA（已做双源回退）；免费模型层有时延与限流波动（如实报告而非掩盖）

## 数据与迭代（PM 实践）

- **北极星**：复访/复用率（完成率衡量单次交付，复访证明"敢用之后还愿意回来"）；指标分层：对内看效率、对外看信任；埋点事件表与 A/B 设计（风险提示位置）见产品文档 §7
- **真实用户反馈驱动的迭代闭环**：上线后由真实用户反馈触发 6 轮产品修复与增强（v32→v37：数据双源回退、ETF 支持、失败可解释、数据溯源、降级兜底）——每一次都有定位、修复、线上验证、留痕

## 工程实现（技术视角）

自研 Multi-Agent 编排内核（DAG + critic 回路 + 租约/guarded finish 崩溃一致性 + 双层预算降级）· 白名单 DSL 确定性回测（评测三元组复算 10/10 全真，1e-9）· RAG 页级引用（embedding 三层回退链 + pgvector/HNSW）· 事件溯源 SSE · Docker Compose 三容器 + GitHub Actions CI + 备份链 + 监控。
完整架构：`docs/architecture.md` ｜ 全部代码与 37 个版本的决策修复史：`docs/BLUEPRINT.md` ｜ 评测：46 用例 0 失败（`docs/eval/results.md`）

## 快速开始（本地开发）

```bash
# 后端（Python 3.11 venv）
cd backend && python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
cp .env.example .env   # 填入 ZHIPU_API_KEY
pytest

# 前端（Node 20+）
cd frontend && npm install && npm run dev   # Vite 代理 /api → :8000
```
