# 事故复盘模板（postmortem）

> **使用前提（provenance.md 硬约束）**：只记录真实发生的事故。**不设数量指标，无事故则无此文档**；不为凑数把预演/演练当事故（预演验证记录归 docs/verification/）。
> 每篇复盘必附完整证据链，缺任一项即为不合格文档。
