> 三条固定话术（已确认）。每条含：输入原文 → 观察点 → 讲解话术 → 预期产物。
> 通用提示：提前 2 分钟打开 http://43.156.248.38；免费模式任务约 5~7 分钟，讲解正好覆盖等待时间；如遇偶发 LLM 过载失败，直接演示降级话术（第 4 节）反而加分。

## 场景 1 · 投研报告 + 白名单策略回测（主打，5~7 分钟）

**输入**（照抄）：
```
分析贵州茅台近三年走势与波动特征，并回测20日均线金叉60日策略，区间2023-06-01至2026-05-31
```

**观察点与话术**（对着实时时间线讲）：
1. 「输入自然语言，Supervisor 先做规划」→ 时间线出现`规划完成 · N 个节点`——*内部生成了 DAG：research 拉数据、strategy 回测、writer 成稿*
2. 「research 正在调真实行情接口」→`工具调用 · market.price_history（600519…）` ✓——*数据来自公开源 AKShare，计算用后复权、展示用不复权，两套口径不混淆*
3. 「策略被翻译成受约束的 DSL」→`工具调用 · engine.run_backtest`——*LLM 只做翻译，不写代码；pydantic 精确 Schema 卡住任何越界参数，白名单外的策略会被明确拒绝（见场景 3）*
4. 「产出物不进对话、走服务端工件库」→`工件生成`——*LLM 上下文只拿句柄和摘要，几百 KB 的行情从不进 token*
6. 净值曲线出现 → *回测是确定性引擎：同一份策略+数据+引擎，任何人复算都是同一组数，评测里 10/10 全对上*
7. 报告出现 → *critic 刚审过一轮：数字必须和工具返回一致，报告底部保留成交假设边界——研究演示，非投资建议*

**预期产物**：时间线（约 30~40 事件）→ 净值曲线图+假设脚注 → 带引用的结论报告。

## 场景 2 · 知识库问答与页级引用（RAG 杀手锏，3~5 分钟）

**输入**：
```
根据知识库回答两个问题：贵州茅台2025年营业收入约多少？量化回测中如何控制最大回撤？须引用原文页码
```

**观察点与话术**：
1. →`工具调用 · rag.search`——*知识库是预置的：巨潮年报节选三份 + 我逐条审过的一百二十条量化方法论，全部标注来源*
2. 报告出现，指着绿色引用链接——*每个论断后面有 [[doc#页码]] 引用，点一下*
3. **点击「📄原文第N页」**，新标签页打开原 PDF 页图片——*页级定位：切块永不跨页，所以引用页码永远是对的；向量检索是 bge-m3，1024 维，挂了自动降级关键词检索并在结果里明示*

**预期产物**：双文档引用的报告（约 10+ 处引用）+ 两个可点开的原页。

## 场景 3 · 正确拒绝（边界即能力，30 秒）

**输入**：
```
帮我用LSTM预测茅台股价并回测
```

**观察点与话术**：时间线很快出现`白名单拒绝 · ...`——*明确的拒绝加支持范围提示，不伪造结果。这版系统支持的是可解释的白名单策略族；「知道不能做什么」是投研工具的底线*——（如遇放行的非确定案例，坦诚说明：免费层模型偶发放行，已在评测里如实记录为待改进项，Issue 跟踪中——诚实展示工程判断）

## 场景 4 · 降级与韧性（备用加分项，随缘演示）

- 断网刷新页面 → 重新打开链接，时间线**从断点完整重建**（事件先落库、Last-Event-ID 回放）
- 如恰遇任务降级 → *双层预算：单任务熔断降级为带标注的部分结果；每日预留式 token 预算击穿前 429*——降级路径本身是设计出来的产品行为
