## 1. 背景与目标

- **背景**：求职作品，目标岗位为量化机构 AI Agent 开发。需要一个面试官可直接在线试用、并完整覆盖岗位 JD 关键词（Prompt/RAG/Function Calling/Workflow/Skill/Memory/Multi-Agent/评估）的作品。
- **定位**：模拟量化私募内部 AI 投研工具的生产形态（单机演示部署，非生产系统非合规终端）。
- **成功标准**：
  1. 面试官打开线上地址，5 分钟内不借助说明完成一次投研任务并获得带引用的报告；
  2. 每个技术关键词都有可演示、可追问到代码与文档的实现；
  3. 全部产出物真实可追溯（见 provenance.md）。

## 2. 用户与使用场景

| 用户 | 场景 |
|---|---|
| 面试官（主要） | 打开链接→输入自然语言需求→观看 Agent 执行时间线→获得报告/回测图表→点开引用原文→查看假设边界脚注 |
| 求职者本人（演示者） | 三套打磨好的演示脚本（投研报告/回测/知识库问答）+ 备份演示视频 |
| 求职者本人（验收者） | 按 acceptance 清单逐轮验收；评测跑分对比 |

## 3. 核心场景与验收标准

### 场景 A：投研报告生成
- **输入**：自然语言（如"分析贵州茅台近三年走势与波动特征"）
- **流程**：Supervisor 分解 DAG → research 拉取真实行情（hfq 计算/raw 展示）→ writer 成稿 → critic 审查（≤2 轮修订）
- **验收**：报告数字与工具返回一致（评测 numbers_ok）；执行时间线完整可回放；断线/刷新后时间线可重建

### 场景 B：白名单策略回测
- **输入**：自然语言策略 + 标的 + 绝对日期区间
- **流程**：strategy Agent 翻译为策略 DSL → 确定性编译 → 向量化回测 → 指标+净值曲线+假设脚注
- **验收**：`{spec, 数据artifact, engine}` 三元组本地复算指标一致（tolerance 1e-9）；白名单外请求明确拒绝（评测 refusal_ok）；回测页脚注展示假设边界
- **【待你确认】1**：默认 fill 口径采用 next_close（保守，T+1 收盘成交）——是否同意？

### 场景 C：知识库问答
- **输入**：知识库范围内问题
- **流程**：rag.search（向量→BM25 降级并明示）→ 答案带 `[[doc_id#页码]]` 引用 → 前端点开渲染原 PDF 页
- **验收**：引用文本真实存在于所引页（机器可校验）；语料 100% 标注来源

## 5. 非功能需求

| 项 | 要求 |
|---|---|
| 单任务预算 | DAG≤6 节点/LLM≤25 次/工具≤40 次/token≤120k/墙钟 300s；超限降级为带标注部分结果 |
| 每日预算 | 预留式 2M token；击穿前 429 |
| 可用性 | 断线重连不丢事件（回放补齐）；进程重启后中断可见+一键重跑 |
| 可观测 | /metrics（Prometheus）：请求/耗时/token/任务状态/预算熔断/溢出/事件失败/状态冲突 |
| 数据一致性 | 工件原子写；备份恢复零悬空（reconcile 断言） |
| 兼容 | 统一 Python 3.11（本地/CI/生产） |
