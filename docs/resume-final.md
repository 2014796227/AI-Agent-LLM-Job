## 二、技术面试官版 · 简历「项目经历」栏（可直接粘贴）

- **自研 Multi-Agent 编排内核**（~2k 行，ADR 记录取舍不用 LangGraph）：Supervisor DAG 规划（≤6 节点）→ research/strategy/writer + critic 反思回路；任务状态机 CAS 抢占 + 租约心跳 + watchdog，guarded finish 保证崩溃一致性（迟到 finish 不覆盖 interrupted、预留释放权唯一）；双层 token 预算：单任务五维熔断优雅降级、日预算预留式击穿前 429
- **确定性回测引擎**：LLM 仅将自然语言策略翻译为 pydantic 严格 Schema 的白名单 DSL（无 eval/exec），hfq 后复权全链路 + fill→shift 契约防未来函数；**评测三元组本地复算 10/10 全真（1e-9 容差）**
- **多源行情接入与数据溯源**：东财→腾讯双源自动回退（应对免费数据源无 SLA 限流）、A 股个股+场内 ETF 支持；页面展示每份行情的来源/行数/拉取时间（数据从接口抓取即打标、随事件流到前端）——**全链路可核查、零编造**
- **RAG 页级可信引用**：不跨页切块 → `[[doc#页]]` 引用前端可点击渲染原 PDF 页（巨潮官方年报）；embedding 三层回退链（智谱 e3→e2→硅基 bge-m3 1024 维）+ HNSW；引用断言命中 15/17
- **事件溯源与可解释性**：事件先落库再推 SSE（bigserial 兼作事件号），断线 Last-Event-ID 回放不丢；任务失败时前端展示错误分类与应对建议（限流/余额/中断分型），降级结果带标注横幅
- **质量与工程文化**：46 用例三层评测（确定性断言/LLM 裁判/人工）0 失败、报告 100% 脚本生成制；29 单测；真实生产事故复盘（PM-001）与 15+ 缺陷"验证驱动修复"全留痕；备份链生产演练零悬空 + 每日 cron

**技术栈**：Python/FastAPI(异步) · PostgreSQL/pgvector · React/TypeScript/ECharts · Docker Compose · GitHub Actions · 智谱 GLM + 硅基 embedding（多模型回退链）· AKShare(东财/腾讯双源) · SSE · Prometheus
